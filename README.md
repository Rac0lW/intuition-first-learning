# intuition-first-learning

A reusable Agent Skill for intuition-first explanations across technical subjects.

## Trigger examples

- `用直觉模式讲一下特征值`
- `帮我建立 borrow checker 的直觉`
- `I know the formula, but I don't feel what it means.`
- `Give me an operational mental model of backpropagation.`

The main skill definition is in `SKILL.md`.
